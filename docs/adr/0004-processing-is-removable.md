# Processing is a removable module

All processing code lives in its own module on each side (`src-tauri/src/processing/` and `src/processing/`). It touches the rest of mÅqtt only through the Message Bus (reading messages, and adding Derived Topics and republished messages), a handful of registered commands, and one entry point each in the Topic Tree and the tab bar. Deleting those folders and their registrations removes the feature without other changes, and the entry points are where a later setting can hide it. Nothing in processing runs until a Pipeline is started, and a Pipeline that falls behind drops messages and reports it instead of slowing the Connections.
